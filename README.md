# 📊 Superstore Sales Dashboard – Excel

An interactive **Superstore Sales Analysis Dashboard** created in Microsoft Excel to analyze sales, profit, orders, customers, regions, categories, and city-level performance.

The project uses **Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, Charts, Slicers, and Filters** to transform raw sales data into an interactive business dashboard.

---

## 📌 Project Overview

The Superstore Sales Dashboard helps businesses understand their sales performance and identify important trends across:

- 📈 Sales
- 💰 Profit
- 🛒 Orders
- 📊 Profit Margin
- 🧾 Average Order Value
- 🔄 Return Rate
- 🌎 Region
- 👥 Customer Segment
- 📦 Category & Sub-Category
- 🏙️ Top Performing Cities
- 📅 Year-wise performance

The dashboard is interactive, allowing users to filter the analysis using **Year** and **Category** slicers.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze overall sales and profit performance.
2. Identify the best-performing regions.
3. Compare sales across customer segments.
4. Analyze category and sub-category performance.
5. Identify cities generating higher profits.
6. Track yearly sales trends.
7. Calculate important business KPIs using DAX.
8. Create an interactive and user-friendly Excel dashboard.
9. Support data-driven business decisions.

---

## ❓ Business Questions

The dashboard answers the following business questions:

- What is the total sales generated?
- What is the total profit?
- How many orders were placed?
- What is the overall profit margin?
- What is the average order value?
- What is the return rate?
- Which region generates the highest sales?
- Which customer segment contributes the most sales?
- Which category has the highest sales?
- Which sub-categories perform well?
- Which cities generate the highest profit?
- How does sales performance change over the years?
- How does performance change after applying different filters?
